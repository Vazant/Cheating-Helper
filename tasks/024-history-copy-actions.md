# 024 — Копирование текста из History

Статус: `TODO — FUTURE`

## Запрос пользователя

Сделать копирование текста из History удобным и понятным.

## Текущее состояние

- Текст сообщений уже выделяется мышью через `user-select: text` (`src/components/views/HistoryView.js:174-180`).
- Отдельного действия Copy и подтверждения успешного копирования нет (`src/components/views/HistoryView.js:382-410`).

## Предлагаемый минимальный вариант

1. Добавить небольшую кнопку `Copy` к каждому сообщению пользователя, ответу AI и результату screen analysis.
2. Копировать только тело выбранного сообщения через Clipboard API, без времени и служебных подписей.
3. После успеха кратко показывать `Copied`; при ошибке — понятное сообщение.
4. Сохранить обычное выделение текста мышью.
5. Не добавлять зависимостей и не менять формат истории.

## Критерии приёмки

- Любой вопрос или ответ копируется одним нажатием.
- В буфере находится точный текст сообщения без timestamp.
- Кнопка доступна с клавиатуры и имеет понятное название.
- Существующие History sessions не требуют миграции.

## Требуется решение пользователя перед реализацией

Нужна кнопка у каждого сообщения или одна кнопка `Copy conversation`, копирующая всю сессию? Рекомендация: кнопка у каждого сообщения; копирование всей сессии можно добавить отдельно только при реальной необходимости.
