## Основные группы проблем

1. **Недоступные модели и 404 — критично.** Issues #408, #358, #352, #339 и закрытый #327 показывают повторяющиеся поломки из-за hardcoded model IDs. Текущий master уже снова содержит отключённый Groq `qwen/qwen3-32b`. PR #385 исправлял прошлую волну Gemini/Gemma, но архитектурная причина осталась.
2. **Квоты и отсутствие прозрачности — высокий приоритет.** Issue #322 сообщает о внезапном Gemini rate limit. Groq-код аналогично не показывает реальные остатки, хотя API их возвращает. Это точно совпадает с задачей предупреждений.
3. **Local AI аварийно закрывается на Windows — высокий приоритет, но уже есть свежий PR.** Issue #421; PR #434 от 2026-07-17 предлагает стабилизацию Whisper. Сначала следует изучить PR, не писать параллельное исправление.
4. **Небезопасное хранение API-ключей — высокий приоритет, уже есть PR #433.** Перед собственной реализацией нужно оценить этот PR.
5. **Язык не сохраняется — средний приоритет, уже есть PR #432.** Issue #404. В текущем master callback сохраняет язык, поэтому нужно проверить точный сценарий/PR, а не дублировать исправление.
6. **Выбор монитора — средний приоритет, уже есть PR #431.** Issue #388 подтверждает hardcoded первый display и ссылается на закрытый PR #279.
7. **Запись длинных вопросов/ручное управление аудио — второй этап.** Issues #382 и #359; требует аудио UX и связано с запланированным Whisper-направлением.
8. **Релизы отстают от master — процессная проблема.** Issue #393: пользователь получает старые model IDs из релиза 0.7.0. Нужна воспроизводимая сборка/release после исправлений.
9. **Запрос других провайдеров — подтверждение направления.** Issue #398; Groq уже добавлен, но без нормального выбора и управления жизненным циклом моделей.
10. **Большинство самых свежих issues — запросы invite code.** Это следствие неработающего/удаляемого Cloud режима, а не отдельные дефекты. В нашем форке разумнее убрать зависимость от invite-only Cloud и ясно вести пользователя к BYOK/Local.

## Приоритет для подтверждения пользователем

1. Надёжная Groq-интеграция: активные модели, реальные лимиты, 95% warnings, понятные 404/429, корректный stream parser.
2. Оценить и при необходимости взять upstream PR #433 (шифрование ключей), #434 (Local AI crash), #431 (мониторы), #432 (язык), не дублируя работу.
3. Убрать путаницу Cloud/invite code из интерфейса и документации.
4. Затем второй этап аудио: длинные вопросы, ручной захват, Whisper.
