# 010 — Защита Gemini от платного использования

Статус: `DONE`

Решение пользователя: Gemini временно полностью отключить, не показывать и не принимать API key.

## Нормализованное требование

Не допускать скрытого перехода на платное использование Gemini после исчерпания бесплатной квоты. Явно показывать состояние исчерпанной квоты, прекращать автоматические запросы и не выполнять платный или межпровайдерный fallback без отдельного решения пользователя.

## Отложено до отдельной задачи повторного включения Gemini

Free Tier guard, Google Search alignment, Live AUDIO output и quota-lock не входят в текущую реализацию, потому что Gemini полностью недоступен из активного приложения.

## Критерии приёмки

- В активном UI нельзя ввести Gemini API key.
- Hosted/BYOK не создаёт Gemini-сессию и не выполняет Gemini HTTP/Live вызовы.
- Local AI продолжает запускаться.
- Сохранённый legacy key не удаляется и не выводится.
- `initialize-gemini` возвращает отказ и не создаёт сессию.
- Audio/image IPC в Groq mode не попадает в Gemini fallback.
- В логах нет Gemini API key.

## Результат анализа

Gemini API key наследует billing проекта. Гарантия отсутствия списаний достигается отдельным проектом с отключённым или непривязанным billing; приложение без Cloud Billing OAuth может только обеспечить защитное поведение и честное пользовательское подтверждение.
